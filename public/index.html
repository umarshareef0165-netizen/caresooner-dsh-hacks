      How it works — honestly

      1. Transparent rules, not a black box. Every result shows its rule trace (R1–R6). The code is plain Python with no machine-learning model and no external API.
      2. Red flags first. Any selected red flag puts emergency safety information first, before anything else.
      3. Early detection = your own record. The tracker shows repeats and change over time so you can describe a pattern accurately to a clinician.
      4. Privacy by design. No account, no database, no tracking. The server is stateless; the tracker lives only in your browser.

      What this is NOT

      • Not a diagnosis, not a treatment recommendation, not a replacement for a clinician or emergency care.
      • Not validated on patients, not tested on real medical records — and it never claims to be.
      • Not a substitute for local emergency services. In an emergency, contact local emergency services immediately.
