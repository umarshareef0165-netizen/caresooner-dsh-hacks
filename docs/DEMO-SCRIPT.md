# Demo video script — CareSooner (target 2:30, user records a real screen capture)

Rules for the recording: real screen capture only, no credentials in any
frame (there are none — no login exists), show the disclaimer on screen,
and say the "general information only, never a diagnosis" line out loud.
Do not record any real person's health details — use the labelled demo
example and one tracker entry you type yourself for the demo.

| Time | What to show | What to say |
|------|--------------|-------------|
| 0:00–0:15 | Home page, disclaimer banner | "CareSooner turns a confusing health concern into plain-language information, red-flag checks, and a visit note — so people reach real care sooner. General information only, never a diagnosis." |
| 0:15–0:45 | Click "Try the labelled demo example" | "This is a labelled demo, not a real person: fever, a few days, getting worse, no red flags." |
| 0:45–1:15 | Press "Show my general-information result" | "It shows the prompt-clinician-contact information, the topic section, questions for a clinician, and the visible rule trace — you can see exactly why each part appeared." |
| 1:15–1:40 | Tick a red flag, re-run | "Now the safety part: tick any red flag and emergency information comes first. And if nothing is ticked, it says clearly that nothing is ruled out." |
| 1:40–2:05 | Tracker: add one dated observation, then "Generate visit note" | "The tracker lives only in your browser, so a repeating pattern is visible. The visit note pulls it together to take to an appointment." |
| 2:05–2:30 | README / tests on screen (brief) | "Python standard library only, no database, no keys, tests cover the safety rules. Built by Umar Shareef for DSH Hacks V2, AI × Healthcare." |

After recording: upload as a public video, paste the link into
`docs/DEVPOST-DRAFT.md` (Try it out links) and into the Devpost draft
